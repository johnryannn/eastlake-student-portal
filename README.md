# Eastlake Conservatory Student Portal

A responsive fictional student-portal concept built with React, TypeScript,
Vite, and Tailwind CSS.

All institutions, identifiers, enrollment details, and student data shown in
this project are fictional. The interface is a design prototype and is not
valid proof of enrollment.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
